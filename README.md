# gameserver 연사 모드

gameserver 마인크래프트 서버에서 쓰는 Fabric 클라이언트 모드입니다. 하는 일은 둘입니다.

- 연사: 연사 총을 들고 좌클릭을 누르고 있으면 계속 쏩니다.
- 조준경 확대(v1.1.0부터): 우클릭으로 조준하면 조준기 배율(아이템 설명의 "배율 ×N")대로 확대하고 조준경 그림을 띄웁니다.
- 쏘는 간격, 탄, 걸림, 배율은 서버가 정합니다. 모드는 좌클릭을 누르고 있는지만 서버에 알립니다.
- 모드가 없어도 서버에 들어갈 수 있습니다. 그때는 좌클릭을 연타해 쏘고, 조준하면 조금만 확대됩니다(아래 "모드 없이 조준할 때").

## 필요한 것

| 파일 | 게임 버전 | 필요한 것 |
|:---|:---|:---|
| `gameserver-fire-1.1.0-mc26.1.2.jar` | Minecraft Java 26.1.2 | Fabric Loader 0.20.1 이상 |

- 파일 이름의 `-mc` 뒤가 게임 버전입니다.
- Fabric API는 따로 받지 않아도 됩니다. 필요한 부분이 jar 안에 있습니다.
- Lunar Client처럼 Fabric 모드를 넣을 수 없는 클라이언트에서는 쓸 수 없습니다. 모드 없이 연타로 쏘면 됩니다.

## 설치

### 공식 런처

1. Fabric Installer(https://fabricmc.net/use/installer/)를 받아 실행합니다.
2. 게임 버전 26.1.2, Loader 0.20.1 이상을 고르고 설치합니다. 런처에 `fabric-loader-…-26.1.2` profile이 생깁니다.
3. 이 저장소의 Releases에서 jar를 받습니다. 아래 "파일 확인"으로 sha256을 맞춰 봅니다.
4. jar를 `mods` 폴더에 넣습니다. 폴더가 없으면 만듭니다.
   - macOS: `~/Library/Application Support/minecraft/mods`
   - Windows: `%APPDATA%\.minecraft\mods`
5. 런처에서 Fabric profile을 골라 게임을 켜고 서버에 들어갑니다.

### Prism Launcher, Modrinth App

26.1.2 Fabric 인스턴스를 만듭니다. 인스턴스의 Java는 25 이상이어야 합니다. jar를 그 인스턴스의 `mods` 폴더에 넣습니다.

## 파일 확인

릴리스 설명에 적힌 sha256과 받은 파일의 sha256이 같아야 합니다.

macOS 터미널:
```zsh
shasum -a 256 gameserver-fire-1.1.0-mc26.1.2.jar
```

Windows PowerShell:
```powershell
Get-FileHash gameserver-fire-1.1.0-mc26.1.2.jar -Algorithm SHA256
```

- 받은 폴더에서 실행합니다. 출력의 긴 16진수가 sha256입니다.
- 값이 다르면 넣지 말고 다시 받습니다.

## 잘 되는지 확인

모드에는 따로 보이는 화면이나 설정이 없습니다. 아래로 확인합니다.

- 게임 메뉴의 Mods 목록에 `Gameserver Fire`가 보입니다. Mods 메뉴는 Mod Menu 같은 모드가 있을 때만 보입니다.
- 연사 총(지금은 M4A1)을 들고 좌클릭을 누르고 있으면 계속 쏩니다. 떼면 바로 멈춥니다.
- 모드가 없으면 누르고 있어도 두 발만 쏘고 멈춥니다. 이것과 다르면 모드가 돌고 있는 것입니다.
- 한 발씩 쏘는 총(Glock, 870, Mosin)은 모드가 있어도 누를 때마다 한 발입니다.
- 인벤토리를 열거나, 칸을 바꾸거나, 게임 창에서 나가면 멈춥니다. 다시 쏘려면 다시 누릅니다.

## 조준경 확대

총을 들고 우클릭을 누르고 있는 동안 조준합니다. 1인칭에서만 확대합니다.

| 조준기 | 배율 | 화면 |
|:---|:---|:---|
| 가늠자 (조준기 없음) | 1.2배 | 확대만 합니다. 십자선과 총이 그대로 보입니다 |
| 도트 조준기 | 1.5배 | 화면 가운데에 빨간 점이 뜹니다. 나머지 화면은 가리지 않습니다 |
| 중거리 조준경 | 3배 | 둥근 렌즈 밖이 검게 가려지고, 가운데에 빨간 꺾쇠가 있는 조준선이 뜹니다 |
| 저격 조준경 | 6배 | 둥근 렌즈 밖이 검게 가려지고, 점 눈금이 있는 가는 십자선이 뜹니다 |

- 배율 값은 서버가 정합니다. 표는 v1.1.0을 낼 때의 값입니다.
- 도트 조준기와 조준경은 그림을 띄우는 동안 바닐라 십자선과 손에 든 총을 숨깁니다.
- 확대하는 동안 마우스 감도는 배율만큼 낮아집니다. 6배면 1/6입니다. 그래서 화면이 움직이는 빠르기는 확대 전과 비슷합니다.
- 시야는 몇 틱에 걸쳐 좁아지지만 감도는 누르는 순간 바로 바뀝니다.
- 날기, 달리기, 게임 설정 "FOV 효과"와 상관없이 같은 배율로 확대합니다.
- 우클릭을 떼거나, 칸을 바꾸거나, 창을 열거나, 3인칭으로 바꾸면 바로 확대를 풉니다.
- 다른 확대 모드(Zoomify 등)와 함께 쓰면 부딪힐 수 있습니다. 이상하면 다른 확대 모드를 빼고 시험합니다.

## 모드 없이 조준할 때

모드가 없으면 서버가 조준 중 이동 속도를 낮춰 시야를 좁힙니다. 바닐라 게임은 이렇게 좁힐 수 있는 폭이 정해져 있습니다. 그래서 배율대로 확대되지 않습니다.

- 가늠자 약 1.18배, 도트 약 1.25배, 중거리 약 1.54배, 저격 약 2배까지만 확대됩니다.
- 게임 설정 "FOV 효과"가 0이면 확대되지 않습니다.
- 조준경 그림은 뜨지 않습니다. v1.0.0도 연사만 되고 확대는 모드 없을 때와 같습니다.

## 서버와 버전이 맞지 않을 때

서버가 채팅으로 "총 연사 모드가 서버와 맞지 않아 쓰지 않습니다. 새 버전을 받아 주세요."라고 알립니다. 그러면 이 저장소의 최신 릴리스를 받아 바꿔 넣습니다.

## 버전

- 서버의 게임 버전이 바뀌면 그 버전용 jar를 새 릴리스로 올립니다.
- jar는 이름의 `-mc` 뒤에 적힌 게임 버전 하나에서만 켜집니다. 작은 업데이트(예: 26.1.2에서 26.1.3)에서도 옛 jar는 켜지지 않습니다. 새 jar로 바꾸거나 빼야 합니다.
- 모드만 고친 경우에도 새 릴리스로 올립니다. 이미 올린 릴리스의 파일은 바꾸지 않습니다.

## 지우기

`mods` 폴더에서 jar를 지웁니다. 다음에 게임을 켜면 모드 없이 돕니다.

## 보내는 정보

- 이 서버에만 보냅니다. 다른 서버와 싱글플레이에서는 아무것도 보내지 않습니다.
- 보내는 것은 좌클릭을 눌렀는지 뗐는지와, 접속할 때 한 번 보내는 모드 버전뿐입니다. 우클릭(조준)은 보내지 않습니다. 서버가 조준 시작과 끝을 배율과 함께 모드에 알려 줍니다.
- 계정, 기기, 다른 키 입력은 보내지 않습니다.
